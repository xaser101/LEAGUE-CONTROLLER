# League Controller

A companion app for the League of Legends client on Windows, by xaser.

- **Profile**: ranks, LP history, match history with both teams
- **Play**: lobbies, queues, auto-accept, queue lockout timer
- **Champ select**: win rates for your lane matchup, rune pages to edit and import, builds, your champion pool
- **Live game**: everyone's rank and record, and your build
- **Friends**: your record with each friend

## Download

Get `LeagueController.exe` from the [latest release](../../releases/latest) and run it. No install needed.

Windows may warn that the app is unrecognised, because it isn't signed. Click **More info**, then **Run anyway**.

The app checks for updates itself and shows **Update to …** in its title bar when a new version is out. What changed in each version is on the [releases page](../../releases).
